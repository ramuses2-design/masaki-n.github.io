# 読者別ハンドブック（連携ガイド）

> **位置づけ**：品質保証（QA）から、**営業・技術・製造・購買**の各部門、および**外注先（お取引先）**へ向けた連携の手引き。
> 「品証と、いつ・何を・どう連携するか」を場面別にまとめたもの。方針マスターの**ブレ防止6原則**と**エスカレーション基準**が土台。
> **考え方の核**：品質は検査で「見つける」より、**前工程で作り込む**。だから各部門・取引先との連携が品質の大半を決める。
> **凡例**：`★`＝特に外すと事故につながる重点項目。`【要確認】`＝GL（masaki）の確定が必要な箇所。各トピック末尾の「関連場面」から、品証内プレイブック（A〜D）へ辿れる。

## 読者別マップ
- **🤝 営業向け**：見積前確認／要求仕様の連携／クレーム一次対応／特採／出荷可否／監査対応／提出書類／仕様変更対応
- **🛠️ 技術向け**：新製品立ち上げ／4M変更／検査基準／設備導入／工程能力・データ活用／化学物質の設計織り込み／再発防止／治具・型管理
- **🏭 製造向け**：日常検査／異常時初動／変化点申告／測定器・校正／不良報告／5S・監査準備／切替初物／作業標準・力量
- **🧺 購買向け**：サプライヤー選定／受入検査／4M変更管理／化学物質エビデンス／不適合対応／監査・改善
- **📦 外注先向け**：求める品質の基本／提出書類／変更の事前連絡／不適合時の連絡／化学物質対応／納入・識別

# S. 営業向け

> **合言葉：「品質は“約束”。約束できないことは持ち帰る」**
> 営業は、お客様の声が最初に入る窓口。ここで拾う情報と、ここで交わす約束が、品質トラブルの起点にも、予防の起点にもなる。困ったら一人で抱えず、早めに品証（GL）へ一報を。

## S1. 引合い・見積前の品質確認
**目的**：受注前に「作れる・測れる・約束できる」を品証と確認し、無理な約束を防ぐ。

**確認して品証へ渡すこと**
- [ ] 要求仕様・規格・図面・適用法規を入手し品証へ共有 ★
- [ ] 用途・使用環境・お客様の重要特性（どこが効く品質か）を聞き取る
- [ ] 当社の実力（工程能力・検査可否・測定可否）を品証に確認 ★
- [ ] 特殊要求（清浄度・化学物質の非含有・トレーサビリティ・提出書類）の有無を確認
- [ ] 「品質面で約束できる範囲」を品証と握ってから見積る

**やってはいけない（NG）**
- 実力を確認せずに納期・スペックを口頭で約束する／「たぶん大丈夫」で受ける

関連場面: C2, C4

## S2. 顧客要求・仕様書の受け取りと連携
**目的**：お客様の要求を、抜け・取り違えなく品証が使える形で渡す。

- [ ] 仕様書・要求規格・検査要求・提出書類（成績書・非含有保証等）を一式で受領 ★
- [ ] 版数（改訂）を必ず最新で共有し、旧版と取り違えない ★
- [ ] 図面・規格の「特別特性」「重要保安部品」等の指定を見落とさない
- [ ] 受領した要求を品証へ連携し、対応可否・条件の回答を得る
- [ ] お客様固有の帳票・Webポータル・提出期限があれば品証と共有

関連場面: C4, D4, D5

## S3. クレーム・苦情の一次対応
**考え方**：「まず事実、約束は持ち帰る」。対外の最終窓口はGL／品証と連携して動く。

- [ ] 事実を聞き取る（現品・ロット・数量・発生状況・お客様の困りごと）★
- [ ] その場で原因・可否・賠償を約束しない ★
- [ ] 即、品証GLへ連携（クレーム・市場不良は**即エスカレーション**事象）★
- [ ] 暫定対応（代替品手配・選別）の要否を品証と決める
- [ ] 回答期限をお客様と握り、社内へ共有する

**やってはいけない（NG）**
- 憶測で原因を語る／確定していないことを約束する／独断で「無償対応します」と言う

**電話一次受けスクリプト例（聞く項目の順番）**
1. お客様名・会社名・連絡先を確認する
2. 製品名・型式・ロット番号（現品・伝票があれば番号）を確認する
3. 発生事象（何がどうなったか、いつ気づいたか）を確認する
4. 数量・発生状況（全数か一部か、使用中のどの段階で発生したか）を確認する
5. お客様の困りごと・ご希望（交換／返金／説明 等）を聞く。この場で可否は答えない★
6. 折り返しのご連絡予定時刻をお約束する★

**言い換え例（NGとOKの対比）**
- NG「たぶん◯◯が原因だと思います」→ OK「原因は社内で確認いたします。分かり次第ご連絡いたします」
- NG「弊社の落ち度ですので、すぐ交換・返金します」→ OK「状況を確認のうえ、対応につきまして改めてご連絡いたします」
- NG「そんなはずはないのですが…」→ OK「詳しい状況を教えていただけますか」

関連場面: B2, B6, B1

## S4. 特採（特別採用）・仕様外品の取り扱い
**考え方**：規格外＝即NGではない。ただし**お客様承認なしに出荷可否を変えない**。

- [ ] 仕様外の可能性は品証へ相談（営業単独で判断しない）★
- [ ] 特採は必ずお客様の承認を取得する（無断で採用しない）★
- [ ] 安全・法規に関わるものは特採の対象外（絶対）★
- [ ] 適用範囲・数量・期限を限定し、恒久化させない
- [ ] 申請・承認・適用の記録を残す
- [ ] 特採で出荷したロットは、後から特定できるよう識別・記録しておく（同一顧客での再発・恒久化の把握に使う）★
- [ ] 特採が繰り返される品目は、規格・工程能力そのものの見直し（C4）を技術・品証へ提起する

関連場面: B5, S1, C4

## S5. 納期・出荷可否の約束の線引き
**目的**：品質判断（出荷可否）と営業判断（納期）の境界を守る。

- [ ] 出荷可否は、品質データに基づく品証の判断を待つ ★
- [ ] 品質保留中のロットを「間に合わせ」で出さない ★
- [ ] 短納期の依頼ほど早く品証へ共有（無理な短納期は品質リスク）
- [ ] GLが最終判断する観点（①信頼関係 ②売上影響 ③費用対効果）に関わる案件は必ずGLへ

関連場面: B1, A3

## S6. 監査・品質会議・顧客訪問での連携
**目的／考え方**：お客様の品質要求・評価を、社内へ正しく持ち帰る。監査・訪問は「見せる場」ではなく「相手の要求水準を知る場」。準備は日常の延長で足りるが、**日程だけは早く共有**しないと準備が間に合わない。

- [ ] 顧客監査・工場訪問の予定は早めに品証へ共有（準備に時間が要る）★
- [ ] 監査・訪問の**目的と範囲**（定期監査／新規採用の審査／クレーム後の確認）を事前に確認して伝える★
- [ ] 見学・撮影の可否、立入り範囲、同席者を事前に決める（当日その場で判断しない）★
- [ ] お客様の品質評価・要求の変化・競合情報を品証へフィードバック
- [ ] 品質会議の決定事項・宿題を記録し、期限を管理する
- [ ] その場で答えられない質問は、**推測で答えず「確認して回答する」**に統一する（期限を添える）★
- [ ] 当日の指摘・宿題は、社内の是正フローに載せて完了まで追う（口頭のまま終わらせない）★
- [ ] 【要確認】顧客監査時の立入り範囲・撮影可否・その場回答してよい範囲

**その場で答えない（持ち帰る）もの**
- 規格値・工程条件・原価に関わる数値、他社の情報、是正の完了時期の確約★

**やってはいけない（NG）**
- 監査日程を直前に共有し、準備を突貫でやらせる（普段どおりを見せるのが最短）
- その場の空気で対応可否や期限を約束する（S5・S8と同じ線引き）

関連場面: D3, A10, S7, S5, S19

## S7. 提出書類・品質エビデンスの取り交わし
**目的**：お客様へ出す品質エビデンスを、正確・期限どおりに用意する。

- [ ] 必要書類（検査成績書・ミルシート・非含有保証・PPAP／初回流動）を品証と確認 ★
- [ ] 提出期限・提出先（帳票／Webポータル）を管理する
- [ ] 記載内容の最終確認（ロット・規格・測定値の整合）★
- [ ] 発行・提出の記録を残す（後で追える状態に）

関連場面: D5, S2

## S8. 顧客要求・仕様の変更対応
**考え方**：変更は「受けたら終わり」でなく、社内へ確実に展開して初めて完了。

- [ ] 変更（規格・図面・検査要求）を最新版で受領し版数を管理 ★
- [ ] 変更内容を品証・技術・製造へ速やかに展開 ★
- [ ] 対応可否・切替時期・在庫（旧仕様品）の扱いを社内と確認
- [ ] お客様へ切替時期・条件を回答する

関連場面: C1, C4, S2

## S9. クレーム後のフォロー・信頼回復
**考え方**：クレーム対応は「是正報告を出したら終わり」ではない。その後の作り込みと関係修復まで含めて“対応”。

- [ ] 是正報告（8D/CAPA）の内容をお客様目線でかみ砕いて説明★
- [ ] 恒久対策の効果を、次回以降の納入実績（データ）で示す★
- [ ] 再発ゼロの期間・改善件数など「良くなった事実」を可視化して共有
- [ ] お客様の要求水準の変化（監査強化・書類追加）を社内へ展開
- [ ] 一件の反省を横展開（同種製品・他顧客）して未然防止につなげる

関連場面: B4, B6, S3

## S10. 値上げ・価格改定交渉時の品質・仕様の整理
**考え方**：価格の話は品質・仕様とセット。何を（仕様・検査水準）どこまで（コスト影響）を整理してから交渉に臨む。

- [ ] 原材料・エネルギー・人件費など、コスト変動の根拠を事実で整理★
- [ ] 現行の仕様・検査水準・付帯サービス（検査成績書等）の棚卸し
- [ ] コスト最適化の代替案（仕様の見直し・数量まとめ）を技術と検討★
- [ ] 品質を落とさずに下げられる余地／落とせない一線を明確化
- [ ] 交渉で合意した仕様・条件は必ず書面化し、社内へ展開

関連場面: S2, P8, C1
関連場面: S2, P8, C1

## S11. 試作・サンプル対応と量産条件の橋渡し
**考え方**：試作品はゴールではなく入口。サンプルで合意した特性を、量産で再現できる条件に落とし込むまで見届ける。

- [ ] サンプル依頼時に、用途・評価項目・合否基準を顧客と明確化する★
- [ ] 試作条件（目付・加工・検査）を技術と記録し、量産との差を把握★
- [ ] 提出サンプルのロット・条件をトレースできるようにする
- [ ] 「サンプルはOK、量産で外れる」を防ぐため量産移行時の条件を技術と確認
- [ ] 量産化の可否・リードタイム・最小ロットを早めに社内で握る
- [ ] 【要確認】サンプル提出時の記録様式・量産移行判定の基準

関連場面: S2, T1, C2

## S12. 環境・サステナビリティ要求（脱炭素・リサイクル素材・エコ認証）への対応窓口
**考え方**：環境・サステナビリティ要求は「営業が受け、技術・購買・品証で答える」チーム対応。曖昧な口約束をせず、確認できる事実に基づいて回答する。

- [ ] 顧客の要求（再生材使用率・CO2・認証・有害物質不使用等）を具体的に文書で受け取る★
- [ ] 回答できる事実（エビデンスの有無）と、確認が必要な事項を切り分ける★
- [ ] リサイクル素材・認証（GRS等）は含有率・トレーサビリティの裏付けを技術・購買と確認
- [ ] バイオベース・生分解性素材への切替要求は、量産での品質妥当性（強度・風合い・ばらつき）が取れるまで数値・時期を約束しない（技術と条件出しを確認：TS29）★
- [ ] 化学物質・法規のエビデンスは既存の仕組み（SDS・chemSHERPA等）と連携（P4・D4）
- [ ] 数値・認証の約束は、社内で裏が取れたものだけを回答する（未確認は「確認します」）
- [ ] 【要確認】自社が提示できる環境エビデンスの範囲・認証の保有状況・回答窓口

関連場面: S2, P4, D4

## S13. 海外顧客・輸出対応（言語・規格・化学法規の差異）の窓口
**考え方**：海外案件は「国内と同じ品質保証を、言語・規格・法規の違いを翻訳して届ける」こと。曖昧な口約束をせず、確認できる事実に基づき、社内（技術・購買・品証）と連携して回答する。

- [ ] 顧客要求（適用規格・言語・化学法規＝REACH/化審法等・書類様式）を文書で受け取る★
- [ ] 国内基準との差異（試験方法・単位・許容値・必要エビデンス）を技術・品証と洗い出す★
- [ ] 化学物質・法規のエビデンスは既存の仕組み（SDS・chemSHERPA）と連携（P4・D4・T6）
- [ ] 輸送・通関・関税や納期の前提を購買・物流と確認し、約束の線引きを明確にする（S5）
- [ ] 数値・認証・法規適合の約束は、社内で裏が取れたものだけ回答する（未確認は「確認します」）
- [ ] 【要確認】自社が対応可能な海外規格・言語・輸出書類の範囲と回答窓口

関連場面: S2, S12, P4, D4

## S14. 相見積り・競合対応時の「品質価値」の伝え方（価格以外の訴求）
**目的／考え方**：価格勝負に流されず、当社の品質・トレーサビリティ・対応力を"見える価値"として顧客に伝え、値引き一辺倒の交渉を避ける。

- [ ] 顧客が本当に困っている品質・供給の不安（クレーム歴・法規対応・納期）を技術/品証と共有して把握する★
- [ ] 当社の強み（検査体制・トレーサビリティ・化学法規対応・改善実績）を具体的な根拠とともに整理する★
- [ ] 「安さ」ではなく「総コスト（不良・手直し・供給停止リスクの低減）」で価値を説明する
- [ ] 過度な品質保証・追加検査の口約束をその場でしない（原価・工数は品証/技術と確認）
- [ ] 失注時も理由を記録し、次の提案・改善に活かす
- [ ] 【要確認】訴求してよい実績・数値の公開範囲、価格決裁の権限

関連場面: S1, S10, A8

## S15. 納入仕様書・品質保証書の読み方（営業が最低限おさえる項目）
**目的／考え方**：納入仕様書・品質保証書は、営業がその場で完全に読み解く必要はない。ただし「顧客に約束してよい範囲」を見誤らないための最低限の読み方は身につけておく。判断に迷う記載は自己解釈で答えず、必ず品証・技術に確認してから回答する。

- [ ] 品名・型式・図面番号・版数が、受注情報・図面と一致しているか確認する★
- [ ] 保証している項目と、保証していない・対象外の項目（免責事項・使用条件の制限）を分けて読む★
- [ ] 適用規格・特性値の欄に意味が分からない専門用語や数値がある場合、そのまま顧客へ回答しない。必ず技術／品証に確認する★
- [ ] 版数・改訂日を確認し、古い版のまま社内保管・提出になっていないか確認する
- [ ] 発行元・発行日・押印など、書類として有効な体裁が整っているか確認する
- [ ] 顧客指定の様式（顧客フォーマットの品質保証書）で提出を求められた場合は、自己判断で記入せず品証と作成する★
- [ ] 【要確認】品証への確認が必須となる記載項目・営業が単独で回答してよい範囲の社内線引き

関連場面: S2, S1, T3, P16

## S16. 顧客アンケート・満足度調査への品質項目の回答連携
**目的／考え方**：顧客満足度調査やアンケートの品質関連項目に、営業が自己判断で回答すると、実態と食い違う回答になりやすい。品証と連携し、事実に基づく回答をそろえる。

- [ ] 品質関連の設問（不良率・クレーム対応・是正の速さ 等）は品証に確認してから回答する★
- [ ] 主観的な評価（満足・不満）と、客観的な実績データを混同せず回答を分ける★
- [ ] 過去のクレーム・是正状況について聞かれた場合、事実と異なる回答をしない★
- [ ] 回答内容・スコアの推移を社内で共有し、低評価項目は改善テーマの候補にする
- [ ] 定型のアンケートは回答テンプレート・過去回答を参照し、回答のブレを防ぐ
- [ ] 【要確認】品質項目への回答フロー・承認者、低評価時の社内エスカレーション基準

関連場面: S9, S6, D6

## S17. 新規引き合い・見積り時の品質要求事項チェックリスト（図面・規格・検査条件・保証範囲の確認漏れ防止）
**目的**：見積り段階での確認漏れが、量産後の「言った・言わない」トラブルの最大の原因になる。S1（引合い・見積前の品質確認）の内容を、実務でそのまま使えるチェックリストに落とし込む。

- [ ] 図面・仕様書は最新版か、版数・改訂日を確認する ★
- [ ] 適用規格・法規（業界規格・安全規格・化学物質規制等）の指定有無を確認する ★
- [ ] 検査条件（検査項目・抜取り基準・合否判定方法）が明記されているか確認する ★
- [ ] 保証範囲（保証期間・保証内容・免責事項）の指定有無を確認する ★
- [ ] 特別特性・重要保安部品の指定がないか確認する
- [ ] 提出書類（成績書・非含有証明・PPAP等）の要求有無を確認する
- [ ] 上記いずれかが不明・未指定の場合は、受注前に品証へ確認し、回答を得てから見積る ★
- [ ] 【要確認】チェックリストの正式様式・保管先

関連場面: S1, S2, T1

## S18. 納期回答と品質保証の両立（検査短縮を安易に約束しない）
**目的**：特急対応・厳しい納期要求に対して、検査を省略・短縮する安易な約束をせず、品質保証と納期回答を両立させる。

- [ ] 納期回答の前に「検査条件（項目・抜取り・全数か否か）を変えずに間に合うか」を製造・品証と確認する ★
- [ ] 検査短縮・省略が必要になりそうな場合は、回答前に必ず品証へ相談する（現場・営業の独断で約束しない）★
- [ ] 短縮を検討する場合も、重要特性・安全に関わる検査項目は対象外とする ★
- [ ] やむを得ず検査条件を変える場合は、リスク（見逃しの可能性）と対象範囲を社内で明文化し、承認者を明確にする ★
- [ ] お客様には「対応可能な納期」と「その条件（検査範囲の変更有無）」をセットで伝える
- [ ] C9（急な増産・特急対応時の品質リスク管理）の社内手順に沿って進める

**やってはいけない（NG）**
- 検査を省略できるかを確認せずに、先に短納期をお客様へ約束してしまう
- 「今回だけ」を理由に、検査条件の変更を記録に残さず口頭で済ませる

**言い換え例**
| NG | OK |
|---|---|
| 「検査を早めれば何とかなると思います」 | 「検査条件を変えずに対応できるか、社内で確認してからお約束します」 |
| 「今回は特別に検査を軽くします」（口頭のみ） | 「対応するには検査範囲の一部見直しが必要です。品証の承認を得たうえでご案内します」 |

関連場面: C9, S1

## S19. 顧客からの技術問い合わせの一次回答の型（答えてよい範囲・持ち帰る範囲）
**目的**：技術的な問い合わせに窓口として素早く反応しつつ、確認不十分な内容を即答して後で訂正する事態を防ぐ。

- [ ] 問い合わせ内容を「一般的な仕様・公開情報の範囲」か「個別の工程・検査条件に踏み込む内容」かで見分ける ★
- [ ] 一般的な仕様・公開資料の範囲は、その場で正確に回答してよい
- [ ] 工程条件・検査基準の詳細、社内固有の数値に関わる内容は、その場で答えず持ち帰る ★
- [ ] 持ち帰る場合は「確認して〇日までに回答する」と期限を明言し、放置しない ★
- [ ] 技術的に不確かな内容は、技術（生産技術・開発）または品証に確認してから回答する ★
- [ ] 回答内容は社内で記録し、同じ問い合わせが他の窓口に来た際に回答がぶれないようにする
- [ ] S6（監査・品質会議・顧客訪問での連携）の想定問答の型と合わせて運用する

**その場で答えてよい範囲の例**
- 公開しているカタログ・仕様書に記載済みの内容
- 既に納入実績のある仕様・規格への適合有無（確認済みのもの）

**持ち帰る範囲の例**
- 個別の工程条件・検査基準の数値
- 未検証の用途・使用環境での適合可否
- 価格・納期に影響する仕様変更の可否

関連場面: S6, T18

# T. 技術向け

> **合言葉：「前提が変わる＝新しいリスクが生まれる」**
> 技術（生産技術・開発）の設計・工程・設備の決定は、品質の作り込みそのもの。品証は「検査で止める前に、工程で作り込む」を掲げている。変更・立ち上げ・基準づくりを、品証と“先に”握るほど後戻りが減る。

## T1. 新製品・量産立ち上げ（APQP／PPAP 的）
**目的**：立ち上げ段階で品質を作り込み、量産後のクレームを防ぐ。

- [ ] 顧客要求・品質特性・規格を初期に明確化し品証と共有 ★
- [ ] 設計審査（DR）・FMEA的なリスク抽出に品証を参画させる ★
- [ ] QC工程表・検査基準・限度見本を品証と作成
- [ ] 初物確認・工程能力（Cp/Cpk）を確認してから量産移行 ★
- [ ] 顧客承認（PPAP／初回流動）の要否を確認
- [ ] 初期流動管理（立ち上げ直後の重点監視）を設定 ★

関連場面: C2, C4, D6

## T2. 4M変更管理（人・機械・材料・方法）
**考え方**：最大のリスクは“暗黙の変更”。**無断変更は禁止**。

- [ ] 人・機械・材料・方法・測定・環境の変更は、事前に品証へ ★
- [ ] 変更前に影響評価・リスクアセスメントを行う
- [ ] 顧客承認・4M変更届の要否を確認 ★
- [ ] 妥当性確認（初物・工程能力・試験）後に切り替える
- [ ] 変更履歴を記録する（いつ・何を・なぜ・誰が）

**やってはいけない（NG）**
- 「良くするだけだから」と、条件・材料・治具を無断で変える ★
- 毎回同じ微調整を繰り返しているのに、標準（条件表・作業標準）を直さないまま放置する（M20）

関連場面: C1, M20, T20

## T11. 工程FMEA（PFMEA）の作成と活用
**考え方**：不良が出てから直すのではなく、工程の弱点を事前に洗い出し、優先順位をつけて手を打つ。

- [ ] 工程を機能単位に分解し、起こりうる故障モード・影響を洗い出す★
- [ ] 発生度・影響度・検出度で評価し、優先度（RPN等）で対策順を決める★
- [ ] 重要度の高い項目は工程・検査基準や管理計画（コントロールプラン）へ反映
- [ ] 4M変更・不具合の再発時にFMEAを見直す運用にする
- [ ] 設計FMEAや検査基準（T3）とひも付け、抜け漏れを防ぐ
- [ ] 【要確認】FMEAの様式・評価基準・見直しトリガー

**PFMEA記入例（架空・1工程分のイメージ）**

| 工程 | 故障モード | 影響 | 発生度 | 影響度 | 検出度 | RPN | 対策 |
|---|---|---|---|---|---|---|---|
| ラミネート工程 | 接着剤の塗布量不足 | 剥離・強度不足 | 3 | 8 | 4 | 96 | 塗布量の自動監視・下限アラーム設置 |
| ラミネート工程 | ロール温度の過昇 | 焦げ・外観不良 | 2 | 6 | 3 | 36 | 温度上限アラーム＋定期点検 |

**記入時の注意（NG例との対比）**
- NG「異常が起きたら対応する」（曖昧）→ OK「塗布量が下限値を下回ったらアラームが鳴り、作業者が設備を停止する」（検出手段と行動を明記）
- NG：発生度・影響度・検出度を勘で埋める → OK：発生度は不良実績データ、影響度は流出時の影響範囲、検出度は現状の検出手段の実力で埋める

## T12. 統計的工程管理（SPC）・管理図の導入と工程能力の見える化
**考え方**：検査で「選り分ける」から、工程で「作り込む」へ。重要特性のばらつきを管理図で監視し、異常を早期に捉えて工程を安定させる。

- [ ] 管理対象の重要特性（目付・幅・強度等）を、影響の大きい工程から絞って選ぶ★
- [ ] Xbar-R管理図などで時系列監視し、管理限界を外れる前の傾向を捉える★
- [ ] 工程能力（Cp／Cpk）を算出し、規格に対する余裕度を見える化する
- [ ] 異常（管理限界逸脱・連続上昇等）が出たときの対応ルールを決めておく（M2と連動）
- [ ] データはPower Automate/kintone等で自動集計し、記録の手間を減らす
- [ ] 【要確認】重要特性の管理限界・Cpk目標値・サンプリング頻度・使用帳票

**異常判定ルールの見方（代表的なもの）**
| ルール | 見方 | 意味 |
|---|---|---|
| 管理限界逸脱 | 1点が管理限界線（UCL/LCL）の外側に出る | 突発的な異常の可能性が高い |
| 連（ラン） | 中心線の片側に規定点数以上が連続する | 工程の平均がシフトしている可能性 |
| 傾向（トレンド） | 複数点が連続して上昇または下降する | 摩耗・劣化など緩やかな変化の兆候 |
| 周期性 | 一定間隔で上下を繰り返す | 交替勤務・原料ロットなど周期要因の疑い |
| 中心化（層別不足） | 点が中心線付近に集まりすぎる | データの層別・サンプリング方法を疑う |
| 二極化 | 点が管理限界付近に偏って分布する | 異なる母集団が混在している可能性 |

**異常検出時の動き方（テキストフロー）**
1. 異常ルールに該当した点を確認し、測定・記録ミスでないかをまず確認する
2. 直近の4M変化（原料・設備・作業者・方法）がないかを確認する（C1と連動）
3. 工程を止めるかどうかは異常の種類・製品への影響度で判断する（M2の声かけ・報告フローに従う）
4. 原因が特定できたら是正し、管理図に処置内容を記録する
5. 原因不明の場合は暫定の頻度アップ等で監視を強化しつつ、原因究明（B3）につなぐ

> 【要確認】連・傾向の判定に用いる点数の社内基準（7点／8点等）、管理図の様式・記録者。

関連場面: T5, M1, D6, T19, T21, T22

## T13. トレーサビリティ設計（ロット管理・識別の作り込み）
**目的**：不良流出時に「どこまで広がったか」を素早く特定できる状態を、工程設計の段階で作り込む。後追いで台帳を足すより、識別・記録の仕組みを最初に決める。

- [ ] ロットの定義（原料ロット・製造ロット・出荷ロットの単位と紐付け）を決める★
- [ ] 識別（ラベル・巻取り番号・製造日時）の付与ルールと記録の残し方を標準化する★
- [ ] 原料〜工程〜検査〜出荷のデータを一意キーでつなげる（kintone/SharePoint等の活用）
- [ ] 変化点（4M変更）とロットの対応が追える形にする（C1・T2）
- [ ] 選別・回収時に必要な粒度（幅方向・巻き単位まで追うか）を品証・営業と合意する（B9）
- [ ] 【要確認】ロット定義・識別様式・記録の保管期間とアクセス権

**ロット番号の採番設計例2種（架空・比較）**
| 方式 | 例（架空） | 長所 | 短所 |
|---|---|---|---|
| 日付連番型 | `20260804-003`（製造日＋当日通し番号） | 発行日が一目で分かる／採番ルールが単純で運用しやすい | 工程条件や設備の違いが番号から読み取れず、絞り込みに検索システムが要る |
| 工程情報埋め込み型 | `L3-A-0804-03`（ライン3・材料区分A・日付・通し番号） | ラインや材料区分で一次絞り込みができ、初動の切り分けが速い | 桁数が増えて記入・照合の手間が増える／区分コードの改廃時に採番ルールの見直しが要る |

## T14. 測定システム解析（MSA／Gage R&R）の実施と判断
**目的／考え方**：測定データを信じてよいかを事前に確かめる。人・測定器のばらつきが大きいと、良品を不良と誤判定したり不良を見逃したりするため、重要特性の測定は解析で検証する。

## T20. 工程条件変更の社内実験計画の立て方（1因子ずつ・判定基準の先決め）
**目的／考え方**：工程条件を勘や思いつきで一度に複数変更すると、結果が良くても悪くても「何が効いたか」が分からなくなる。変える条件を絞り、判定基準を先に決めてから実験することで、再現性のある結論を得る。

- [ ] 変更したい条件（因子）を洗い出し、まず1因子ずつ変えて確認する（複数同時変更は避ける）★
- [ ] 実験前に「何を測るか」「合否・採否の判定基準」を先に決めておく（結果を見てから基準を決めない）★
- [ ] 比較対象となる現行条件（対照区）を必ず設け、変更区と条件をそろえて比較する ★
- [ ] サンプル数・測定回数をあらかじめ決め、母数不足で結論を急がない
- [ ] 実験条件・結果・判定・実施者・日付を記録様式に残す（口頭やメモだけで終わらせない）★
- [ ] 良い結果が出ても、正式な工程条件への反映はC1（4M変更管理）の手順に沿って行う ★
- [ ] 想定外の結果が出た場合の中断基準（安全・品質に影響が出たら即中止）を先に決めておく

**記録様式の項目例**
- 実験目的・変更する条件（因子）と変更しない条件
- 対照区・変更区の条件一覧
- 判定基準（先に決めたもの）・サンプル数
- 結果データ・判定・次のアクション（採用／不採用／追加検証）
- 実施者・確認者・日付

> 【要確認】社内実験記録の正式様式・承認者、量産条件反映までの承認フロー。

## T21. 検査基準書の作り方（判定基準の書き方・写真／限度見本の使い分け）
**目的／考え方**：検査基準書は「誰が検査しても同じ判定になる」ための土台。判定基準があいまいだと、検査員によって合否が割れ、クレームや過検査の原因になる。

- [ ] 検査項目ごとに、合否の判定基準を数値・文言のどちらか、または両方で明確に書く（「きれいであること」等の曖昧表現を避ける）★
- [ ] 数値化しにくい外観等の項目は、写真または限度見本（現物）を用意し、基準書から参照できるようにする ★
- [ ] 写真は「良品」「限界（ぎりぎり合格）」「不合格」の3段階を最低限そろえる
- [ ] 検査方法（使用する測定器・見る角度・照明条件など）を具体的に指定する
- [ ] 限度見本は劣化・退色するため、更新・照合のルール（M14）と連動させる ★
- [ ] 基準書の改訂履歴（版数・改訂日・改訂理由・承認者）を残し、旧版が現場に残らないようにする ★
- [ ] 新設・改訂した基準書は、検査員へ周知し理解度を確認してから運用開始する

**判定基準の書き方（数値化しにくい項目の例）**
| 項目 | 悪い書き方 | 良い書き方 |
|---|---|---|
| キズ・汚れ | 「きれいであること」 | 「長さ〇mm以下、1面あたり〇個以下（限度見本No.〇参照）」 |
| 色調 | 「著しい色差がないこと」 | 「限度見本と比較し目視で判定、または色差計でΔE〇以下（社内基準は【要確認】）」 |
| 異物 | 「異物がないこと」 | 「〇mm以上の異物混入なし（検出方法・検出限界を明記）」 |

> 【要確認】限度見本の管理番号体系・改訂承認者、写真基準の保管形式。

関連場面: M14, T12

## T22. 検査データの統計処理でやりがちな誤り5類型（n数不足・外れ値の恣意的除外・平均だけで判断・工程能力の前提無視・丸めの誤り）
**目的／考え方**：T12（SPC）やT14（MSA）で仕組みを整えても、データの読み方を誤れば判断そのものが崩れる。よくある誤りを型として知っておくことで、統計処理の結果を鵜呑みにせず正しく使える。

- [ ] n数（サンプル数）が少なすぎる状態で「傾向がある／ない」を断定していないかを確認する★
- [ ] 外れ値を、明確な理由（測定ミス・記録ミス等）なく「都合が悪いから」除外していないかを確認する★
- [ ] 平均値だけで合否・傾向を判断せず、ばらつき（範囲・標準偏差）も併せて見る★
- [ ] 工程能力指数（Cp／Cpk）は分布が正規分布に近いことが前提であり、前提が崩れている場合はそのまま適用しない★
- [ ] 測定値の丸め方（四捨五入の位置・タイミング）が結果に影響していないかを確認する
- [ ] 【要確認】社内で正規性・独立性を確認する具体的な手順、外れ値除外の承認ルート

**5類型と気づき方の目安**
| 類型 | 起きやすい場面 | 気づき方の目安 |
|---|---|---|
| n数不足 | 立ち上げ初期・少量ロットでの判断 | 「何個測ったか」を必ず確認する。数個で結論を出さない |
| 外れ値の恣意的除外 | 規格外れのデータが出たとき | 除外理由を記録に残せるか自問する。記録できないなら除外しない |
| 平均だけで判断 | 検査結果のサマリー報告 | 平均と一緒に最大・最小・ばらつきの指標が示されているか確認する |
| 工程能力の前提無視 | Cp／Cpkをそのまま使う場面 | データのヒストグラムを一度見る。分布が歪んでいないか確認する（T12と連動） |
| 丸めの誤り | 規格値ぎりぎりのデータ判定 | 丸める前の生データで合否を判定しているか確認する |

> これらは特別な統計知識がなくても、「n数は？」「外れ値を外した理由は？」と問い直すだけで多くは防げる。判断に迷う場合はT5（工程能力調査）・T12（SPC）の担当者に確認する。

関連場面: T12, T14, T5

# M. 製造向け

> **合言葉：「異常はまず止める、それから直す」／「自己流にしない」**
> 品質は検査で見つける前に、工程で作り込む。現場の一つひとつの操作・記録・気づきが品質そのもの。難しい理屈より「これだけは守る」を優先。**悪い情報ほど早く**、ためらわず上げてほしい（責めるためではなく、仕組みで直すため）。

## M1. 日常の検査・検査表運用
**目的**：決めたとおりに測り、そのまま記録する。

- [ ] 始業前点検（測定器・標準・限度見本）★
- [ ] 検査基準どおりに実施する（自己流にしない）★
- [ ] 抜取／全数の区分を守る

## M2. 異常が出たときの初動（まず止める）

## M4. 測定器・校正の順守
**目的／考え方**：「正しく測れる道具」でしか判定しない。測定器が狂っていると、**不良を良品と判定して流出**する。しかも記録上は「合格」なので、後から気づきにくい。だから測る前に道具を確認する。

- [ ] 校正期限切れの測定器を使わない ★
- [ ] 使用前点検（ゼロ点・ばらつき）を行う
- [ ] 校正ラベル・識別を確認する（ラベルが無い・読めない器は使わない）★
- [ ] 落とした・ぶつけた・水濡れした測定器は、期限内でも使用を止めて連絡する★
- [ ] おかしいと思ったら使用を止めて連絡（その器で測った品の扱いは品証が判断）★
- [ ] 自分で調整・分解しない（「直したつもり」が一番危ない）★

**校正切れ・異常が分かったときは「さかのぼる」**
- [ ] その測定器で**前回の正常確認以降に測ったロット**を洗い出す（測った本人が分かるうちに）★
- [ ] 該当ロットの出荷状況を確認し、出荷済みがあれば即・品証へ（B1のトリアージへ）★
- [ ] 「今日から新しい器で測る」だけで終わらせない。過去の判定が有効かどうかは品証が判断する★

**やってはいけない（NG）**
- 校正期限が「もうすぐ切れる」器を、切れるまで使い切る
- 期限切れに気づいたが、測った結果は問題なかったので黙っておく★

## M10. ヒューマンエラー防止（ポカヨケ・指差呼称・ダブルチェック）
**考え方**：「気をつける」だけに頼らない。間違えられない仕組み（ポカヨケ）で品質を守る。

- [ ] 取り違え・付け忘れ・数量ミスが起きやすい工程を洗い出す★
- [ ] 治具・色分け・表示・システムチェックで“物理的に防ぐ”工夫を入れる★
- [ ] 重要工程は指差呼称・ダブルチェックを標準作業に組み込む
- [ ] 発生したエラーは責めずに記録し、仕組みの改善につなげる
- [ ] 【要確認】重要管理点（取り違え厳禁工程）とポカヨケの標準

**ポカヨケ事例集（不織布・シート工程の例、原理別・架空の一般例）**

**物理的形状で防ぐ**
- 巻取り軸のコアサイズを製品ごとに変え、違う品種のロールが物理的に装着できないようにする
- スリット刃のセット治具を製品幅ごとに専用化し、誤った幅で組み付けられないようにする
- 原反の巻き方向・表裏を治具の突起やガイドで固定し、逆向きにセットできない構造にする

**順序・手順で防ぐ**
- 始業点検表にチェック欄を設け、点検を飛ばすと次工程の記録欄に進めない様式にする
- 4M変更後は「試し運転→初品確認→本生産」の順序をシステム上で強制し、初品確認が未完了だと本生産の記録が入力できないようにする
- 材料の払い出しをロット番号のスキャン照合式にし、指示書と異なるロットはスキャンが通らないようにする

**検知・警報で防ぐ**
- 目付・幅などの重要特性にインラインセンサーを設置し、規格外れを検知したら自動でラインを止める、または警報を出す
- 金属検出機・異物検出機を出口側に設置し、検出時は自動で当該区間を選別対象として排出する
- ラベル・表示の貼付有無を画像センサーで検知し、貼り忘れのまま次工程へ進めないようにする

> 【要確認】上記は一般化した架空例。実際に採用しているポカヨケの種類・設置箇所・仕様は工程・設備により異なるため現場の標準を確認すること。

## M18. 不適合品の隔離・識別表示のルール（赤札・区画・移動禁止と解除の手順）
**目的／考え方**：不適合品を「見た目で分かる状態」にしておかないと、良品と混じって流出する。識別表示と隔離のルールを決め、解除の手順まで明確にしておく。

- [ ] 不適合品と判明したら、直ちに識別表示（赤札・不合格ラベル等）を貼付する ★
- [ ] 隔離区画（専用の置き場・施錠管理等）を決め、良品と混在させない ★
- [ ] 隔離中の不適合品は、承認者の許可なく移動・使用・出荷しない ★
- [ ] 識別表示の様式（色・記載項目：品名・ロット・不適合内容・発見日）を統一する
- [ ] 解除（良品として扱う）の判断は、M17の再開判断と同じ考え方で承認者を明確にする ★
- [ ] 隔離・解除の記録を残し、後から経緯を追えるようにする
- [ ] 【要確認】識別表示の正式様式、隔離区画の設置基準

関連場面: M17, B2, B5

## M19. 清掃・異物管理の実務（清掃基準・持ち込み物ルール・毛髪／繊維くず対策）
**目的／考え方**：異物混入の多くは、日々の清掃・持ち込み物の管理が崩れたところから起きる。「気づいたら汚れていた」ではなく、いつ・どこを・どう清掃するかを決めて回す。

- [ ] 清掃箇所・頻度（始業前／休憩後／終業時など）を区域ごとに一覧化し、担当者を明確にする ★
- [ ] 清掃に使う道具（ブラシ・粘着ローラー・エアブロー等）は用途を分け、清掃自体が異物の発生源にならないようにする ★
- [ ] 作業着・帽子・マスクの着用ルール（毛髪・繊維くずの持ち込み防止）を徹底し、乱れがあれば入場させない ★
- [ ] 現場への私物・包装資材（段ボール片・ビニール片など）の持ち込みルールを決め、区域の出入口で管理する
- [ ] 工具・部品などの一時的な現場持ち込みは、置き場所と持ち出し確認（工具のカウント等）をルール化する ★
- [ ] 清掃実施の記録（実施者・日時・チェック結果）を残し、抜けが分かるようにする
- [ ] 異物の発生源が特定できた場合は、清掃頻度・ルールの見直しにつなげる（M10ポカヨケ事例と連携）
- [ ] M12（温湿度・環境管理）の区域管理と合わせて、環境全体で異物リスクを下げる

**持ち込み物ルールの例**
| 区分 | 対応 |
|---|---|
| 私物（飲食物・装飾品等） | 定められた休憩室以外への持ち込み禁止 |
| 包装資材（外装段ボール・ビニール） | 区域入口で開梱・除去し、内部へ持ち込まない |
| 工具・治具の一時持ち込み | 持ち込み時に数量を記録し、退出時に同数を確認 |

> 【要確認】区域ごとの清掃基準・頻度の正式な一覧、持ち込み物ルールの適用範囲（外部業者含むか）。

関連場面: M12, M10

## M20. 設備パラメータを勝手に調整してはいけない理由（変更管理との関係・調整してよい範囲の考え方）
**目的／考え方**：品質が不安定なとき、現場の判断で設備パラメータ（温度・速度・張力等）を微調整したくなる場面は多い。だが、パラメータは「材料・方法」の一部であり、無断で変えれば実質的な4M変更（M3）になる。決めるべきは「何を・どこまでは現場判断で動かしてよいか」を先に線引きしておくこと。

- [ ] まず、そのパラメータ調整が「決められた範囲内の微調整（現場判断可）」か「範囲外の変更（変更管理が必要）」かを、事前に決めた線引きで判断する★
- [ ] 線引きがない・迷う場合は、変更管理が必要な側として扱う（迷ったときに緩い方へ倒さない）★
- [ ] 良かれと思って調整した結果を、後から「なぜ変えたのか分からない」状態にしない。変更前の値・変更理由・変更者を必ず記録する★
- [ ] 調整後は、変更前の基準に対して品質が維持できているかを確認してから本採用にする（初物確認・工程能力の再取得。C1と連動）★
- [ ] 「毎回同じ調整をしている」パラメータがあれば、それは現場判断の範囲ではなく、標準の見直し（作業標準・条件表の改訂）が必要というサイン★
- [ ] 調整権限者（誰が・どの範囲まで判断してよいか）を工程ごとに明確にし、権限のない人が触れない仕組み（パスワード・施錠等）も検討する
- [ ] 【要確認】設備・工程ごとの「現場判断可の範囲」の正式な一覧、調整権限者の指定

**現場判断可・変更管理が必要の考え方（例）**
| 区分 | 例 | 扱い |
|---|---|---|
| 現場判断可（範囲内の微調整） | 決められた許容幅の中での温度・速度の微調整 | 記録を残せば当日中に対応可 |
| 変更管理が必要（範囲外・恒常的な変更） | 許容幅を超える設定変更、条件表そのものの変更 | M3の4M変化点申告・C1の変更申請ルートに乗せる |

> 【要確認】許容幅の数値そのものは工程・設備ごとに異なるため、各工程の条件表・作業標準を正とする。

関連場面: M3, C1

## M21. 作業標準どおりにできないときの申告の仕方（守れない標準は変える）
**目的／考え方**：作業標準は「守るもの」だが、現場条件が変わって守れない・守りにくい標準は、黙って自己流にせず改訂提案として上げる。守れない標準を放置すると、表向きは順守・実際は自己流という一番危険な状態になる。

- [ ] 標準どおりにできない・やりにくいと感じたら、まず自己判断で変えず現状のまま申告する★
- [ ] 申告時は「何が」「どの条件で」守れないかを具体的に伝える（感覚だけで終わらせない）★
- [ ] 申告先（班長・GL等）と、申告してよいタイミング（気づいた時点で・朝礼で等）を決めておく★
- [ ] 申告が改善提案（M15）につながる場合は、そちらの手順で正式に提案する
- [ ] 標準改訂が決まるまでの間は、現行標準を守りつつ暫定の注意点を申し送る★
- [ ] 改訂後は変更内容と理由を関係者に周知し、旧標準に戻らないようにする（C1の4M変更管理と連動）
- [ ] 【要確認】申告の正式な様式・申告先、改訂の決裁ルート

**受け止める側（班長・GL）の対応の型**
- [ ] 申告してくれたことをまず受け止める（言い出しにくいことを言ってくれた事実を評価する）★
- [ ] 「守れない」を個人の力量不足で片付けず、標準側の問題である可能性から先に検討する★
- [ ] 現場条件（設備・材料・作業量）が変わっていないかを確認し、必要ならC1の4M変更管理に乗せる
- [ ] 改訂の要否を判断できない場合は、判断できる人（技術・品証）へつなぐまでの期限を決める
- [ ] 改訂を見送る場合も、見送った理由を申告者に必ず返す（言っても変わらないと思わせない）

> 標準を守れない状態を「本人の頑張り」で埋め合わせる運用を続けると、標準と実態が乖離し、引き継ぎ時や異常時に危険な自己流が表面化する。

関連場面: M3, C1, E6, M8

# P. 購買向け

> **合言葉：「入口で止める。エビデンスで守る」**
> 購買（調達）は、社外から入る品質の“入口”。良いサプライヤーを選び、変化を管理し、エビデンスを集めることが、後工程のトラブルを防ぐ。品証と連携して、受入基準・是正・監査を回す。三本柱のひとつ「サプライヤーとの品質改善」の実働部隊。

## P1. サプライヤーの選定・承認
**目的**：新規の調達先は、品質の実力を確認してから採用する。

- [ ] 新規サプライヤーの品質評価（体制・認証・実績）を品証と実施 ★
- [ ] 初回サンプル・初品の妥当性を確認
- [ ] 品質保証条件（規格・検査・提出書類・変更連絡義務）を取り決め ★
- [ ] 承認の記録を残す

関連場面: C2, D3

## P2. 受入検査・受入基準
**目的**：何を・どの基準で受け入れるかを品証と決め、抜け漏れなく確認する。

- [ ] 受入検査基準（項目・抜取／全数・判定）を品証と設定 ★
- [ ] ミルシート・成績書の確認と保管
- [ ] 不適合時の処置ルール（受入保留・返品・特採の要否）
- [ ] トレーサビリティ（ロット・入荷日）を確保

関連場面: D1, B5, P10

## P3. サプライヤーの4M変更・製造中止管理
**考え方**：仕入品の“暗黙の変更”は自社クレームの主因。事前連絡を義務化する。

- [ ] サプライヤーに4M変更の事前連絡を求める（契約・覚書に明記）★
- [ ] 変更時は初品・妥当性を再確認 ★
- [ ] 製造中止（EOL）・材料変更の早期把握と代替検討
- [ ] 変更履歴を記録する

関連場面: C1, D4

## P4. 化学物質・法規エビデンスの収集
**目的**：顧客要求・法規に応えるため、成分情報を確実に集める。

- [ ] SDS・chemSHERPA・IMDS・非含有保証をサプライヤーから収集 ★
- [ ] 顧客要求基準・適用法規（RoHS／REACH）との突合 ★
- [ ] 材料・工程変更時の再取得（変更管理と連動）
- [ ] 記録・トレーサビリティを残す

関連場面: D4, C1

## P5. サプライヤー不適合・クレーム対応
**目的**：仕入品の不具合を、是正まで確実に回す。

- [ ] 不適合の封じ込め（受入停止・在庫隔離）★
- [ ] サプライヤーへ是正要求（原因・恒久対策・横展開／8D）★
- [ ] 是正の期限管理と効果確認
- [ ] スコア・評価へ反映（継続取引の判断材料に）

**是正要求（SCAR）依頼文例（社外送付・一般化した架空例）**
> 貴社ご担当者様
> 平素より格別のお引き立てを賜り、御礼申し上げます。
> 下記の件につきまして、原因究明および是正処置のご対応をお願いいたします。
> ・対象品名／型式／ロット番号：（記入）
> ・不適合内容：（事実に基づき具体的に記載。憶測は書かない）
> ・発見日／発見工程：（記入）
> ・ご対応いただきたい内容：①暫定処置（流出防止）②原因（真因）③恒久対策と完了予定日④横展開の要否
> ・ご回答期限：（記入）
> 恐れ入りますが、期限までにご回答賜りますようお願い申し上げます。

**是正要求書 記入例（架空・一般化）**
| 項目 | 記入内容の例 |
|---|---|
| 是正要求番号 | SCAR-2601（架空の通し番号） |
| 不適合内容 | 受入検査にて外観に◯◯を確認、事実のみ記載 |
| 暫定処置 | 該当ロットの出荷停止・選別実施（実施日を明記） |
| 原因（暫定→真因） | 「作業ミス」で終えず、なぜ起きたかの仕組み側の要因まで記載 |
| 恒久対策 | 対策内容と完了予定日をセットで記載 |
| 横展開 | 同一原因が他ライン・他製品に及ぶ可能性の有無 |
| 効果確認 | いつ・何を確認して有効性ありと判断するか |

**NG例と改善例**
- NG「今後気をつけます」で終わる回答 → OK 原因（真因）と恒久対策・完了予定日を明記した回答
- NG 原因を「作業者のミス」だけで終える → OK なぜミスが起きたか（標準・確認体制・仕組み側）まで掘り下げる
- NG 是正要求の回答期限を決めずに送付 → OK 回答期限を明記し、期限管理表で追跡する

関連場面: B2, B4

## P6. サプライヤー監査・品質改善の伴走
**考え方**：選ぶだけでなく、育てる。三本柱「サプライヤー品質改善」の実務。

- [ ] 定期監査（品質体制・工程・記録）を計画・実施 ★
- [ ] 課題の共有と改善の伴走
- [ ] 重要サプライヤーの複数社化・BCPの検討
- [ ] 監査・改善の結果をマネジメントレビューへ

関連場面: D3, D6, A7, P5

## P7. 供給BCP・二社購買（供給途絶リスク）
**考え方**：品質が良くても「入らない」と止まる。重要材料は供給途絶リスクを品質と同じ土俵で管理する。

- [ ] 重要材料・単一供給（シングルソース）品目を棚卸し★
- [ ] 二社購買・代替材の可否を技術・品証と検討（同等性評価）★
- [ ] 供給業者のBCP・在庫方針・リードタイムを把握
- [ ] 災害・需給逼迫時の優先供給・連絡ルートを事前に取り決め
- [ ] 代替材の採用は4M変更として品質妥当性を確認（無条件切替は不可）
- [ ] 供給途絶は「災害」だけではない。取引先の統合・買収・事業売却・拠点集約でも、供給条件と品質保証体制は動く★
- [ ] 重要材料の供給元について、業界再編の兆候（統合・スピンオフ・工場閉鎖の公表）を掴んだら、その時点で影響評価を始める（TS30）★
- [ ] 【要確認】重要材料リストと最低在庫・安全在庫の基準

関連場面: P1, P3, C1, TS30

## P8. 原材料の値上げ・代替材の評価と切替管理
**考え方**：コスト・供給リスク対応で材料を変える時こそ、品質と法規の確認を飛ばさない。

- [ ] 値上げ／供給不安の材料をリスト化し、影響度で優先順位づけ★
- [ ] 代替材の候補について、規格・特性・法規（SDS/含有情報）を確認★
- [ ] 少量での評価（受入・工程・製品特性）を技術と連携して実施
- [ ] 4M変更として正式に管理し、切替時期・在庫の入れ替えを計画
- [ ] 【要確認】代替材の承認基準・評価項目・顧客承認の要否

関連場面: P1, P3, C1, P17

## P9. 受入ロット管理・FIFO と保管品質の維持
**考え方**：良い材料を買っても、保管で劣化すれば台無し。ロットを識別し、先入れ先出しと保管環境で品質を守る。

- [ ] 受入時にロット番号・数量・試験成績書を記録し識別する★
- [ ] 先入れ先出し（FIFO）を徹底し、在庫の滞留・期限切れを防ぐ★
- [ ] 温湿度・直射・においなど、材料ごとの保管条件を守る
- [ ] 使用期限・再評価の要否を管理し、期限切れ材料の混入を防ぐ
- [ ] トレーサビリティのため、材料ロットと製造ロットの紐付けを維持
- [ ] 【要確認】材料別の保管条件・使用期限・受入記録の様式

**保管環境チェックリスト（現物確認・7項目）**
- [ ] 保管場所の温湿度が材料ごとの規定範囲内であることを記録で確認する★
- [ ] 直射日光が当たる位置に材料が置かれていないか現物を確認する★
- [ ] 段積みの高さ・重量が規定を超えていないか（変形・荷崩れリスク）を確認する★
- [ ] 先入れ先出し（FIFO）が守られているか、棚・ロットの並び順を現物で確認する★
- [ ] 使用期限・受入日が記載されたラベルが劣化・脱落していないか確認する
- [ ] 保管場所周辺に異物混入・汚染の原因（粉塵・薬品・水濡れ等）がないか確認する
- [ ] 期限切れ・要再評価の材料が識別され、通常在庫と混在していないか確認する

> チェックは棚卸しのタイミングに合わせて定期実施し、記録上の在庫と現物の保管状態を突き合わせる。

関連場面: P2, D4, C1, C13

## P10. 副資材・包装資材の品質管理（インク・粘着・段ボール等の変更管理）
**考え方**：主原料だけでなく、インク・粘着剤・離型紙・段ボール等の副資材も品質・法規に影響する。「副資材だから」と変更管理を緩めない。

- [ ] 副資材も含有化学物質・法規（SDS等）のエビデンスを収集・保管する★
- [ ] 副資材メーカーの材質・製法変更（4M変更）を事前連絡させる仕組みを作る★
- [ ] 印刷インク・粘着剤の変更は、製品側の品質（付着・臭気・移行）への影響を技術と確認
- [ ] 包装（段ボール・フィルム）の変更は輸送ダメージ・結露への影響を確認（TS15と連動）
- [ ] 副資材の受入・保管条件（吸湿・期限）を主原料に準じて管理する
- [ ] 【要確認】副資材の受入基準・変更連絡ルール・対象副資材のリスト

関連場面: P3, P4, TS15, C12

## P11. 輸入材・調達リスク管理（為替・関税・長納期の変動対応）
**目的**：円安・関税・海運の変動は、原材料のコストと供給の両方を揺らす。価格転嫁と供給途絶の両リスクを、品質を落とさずに管理する。

- [ ] 輸入材・海外依存度の高い品目を洗い出し、為替・関税変動の影響度を把握する★
- [ ] 長納期品・単一調達品はリードタイムと安全在庫を見直す（P7・P9）★
- [ ] 代替材・国内代替先の候補を評価し、切替時は品質同等性を技術・品証と確認（P8）
- [ ] 価格改定・条件変更はサプライヤーの4M/製造中止情報と合わせて管理（P3）
- [ ] コスト変動の見通しは営業の価格交渉（S10）と共有し、無理な在庫積み増しを避ける
- [ ] 【要確認】重点輸入品目・安全在庫水準・代替先の承認状況

**為替前提を「書いて」おく（後から揉めないために）**
- [ ] 見積書・価格改定の資料には、前提とした為替水準と有効期限を明記する。前提を書かない見積りは、変動時に値上げ交渉の根拠を失う★

## P16. 価格改定・契約更新時の品質条件の見直し（仕様書・検査条件・保証範囲の有効期限確認）
**目的／考え方**：価格改定や契約更新の交渉は営業・購買が主導することが多く、品質条件は「今までどおり」として素通りしがちだ。しかし仕様書・検査条件・保証範囲には有効期限や前提条件があり、契約更新のタイミングは品質条件を棚卸しする良い機会でもある。

- [ ] 契約更新・価格改定の話が動き出したら、対象品目の仕様書・検査条件・保証範囲の最新版と有効期限を確認する★
- [ ] 前回契約時から工程・材料・検査体制に変更がないかを、購買・技術と突き合わせる★
- [ ] 検査条件（抜取り数・判定基準）が緩和・省略される交渉になっていないか、品質保証の立場から確認する★
- [ ] 保証範囲（保証期間・免責事項）の見直しがある場合は、過去のクレーム・是正実績と矛盾しないか確認する
- [ ] S15（納入仕様書・品質保証書の読み方）と合わせて、営業側の交渉窓口と品質条件の解釈にズレがないか事前にすり合わせる★
- [ ] 価格改定を理由に検査簡略化や納期短縮を安易に約束しない（S18の考え方と連動）
- [ ] 見直し後の条件は、社内の仕様書・検査基準書に反映し、旧条件が現場に残らないようにする
- [ ] 【要確認】契約更新時の品質条件見直しの正式な手順・承認フロー

関連場面: S15, S10

## P17. 廃番・供給終了通知を受けたときの動き（代替評価の依頼・在庫確保・顧客連絡）
**目的／考え方**：サプライヤーから原材料・部材の廃番（供給終了）通知を受けたとき、対応が遅れると量産が止まる。通知を受けた時点で「代替評価」「在庫確保」「顧客連絡」を並行して動かす。

- [ ] 廃番通知を受けたら、対象品目・最終受注期限（ラストバイ）・在庫状況をまず確認する★

- [ ] 影響が及ぶ顧客・製品を洗い出し、いつまでに何を連絡する必要があるかを整理する（S15・S17と連携）★

- [ ] 代替が見つからない場合の選択肢（自社在庫での延命・製品自体の仕様変更・生産終了）を早めに関係者で検討する
- [ ] 記録として、廃番通知日・対応方針・代替評価結果・顧客連絡の履歴を残す
- [ ] 【要確認】廃番対応の社内フロー・ラストバイ判断の権限者

関連場面: P8, TS30
