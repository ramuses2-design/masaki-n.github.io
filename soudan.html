セルフ診断

考えを整理するためのツールを置いておく場所です。答えを出してくれるものではなく、「自分がいま何をどう考えているか」「自分はどこで活きるか」を自分で見えるようにするための道具です。診断結果はどれも人物評価ではなく、人事評価にも使いません。

自分の持ち味を知る3ツール

点数の高さを競うものではありません。強く出たところが「自分が活きる場面」、低いところは「他の人に任せてよいところ」として出ます。まずここから始めるのがおすすめです。

CK12 🧩 活きどころ（貢献タイプ）診断 気づく／整える／支える／詰める／進める／つなぐ／深める／生み出す の8タイプで、自分がどんな場面で力を発揮するかを見ます。組むと強い相手まで出ます。 約8〜12分32問・8タイプ優劣を出さない タイプを見る → CK13 🧭 力が出る条件（働き方の相性）診断 一人で深く⇔人と一緒に、長距離型⇔短距離型、型がある方が力が出る⇔自由度が要る など7つの軸。どんな条件のときに力を出しやすいかと、まわりに伝える言い方が出ます。 約8〜10分28問・7軸優劣を出さない 条件を見る → CK11 🌱 気づき・配慮（支える力）診断 先回りの気づき・場を整える・人への配慮・情報の橋渡し・抜け漏れを防ぐ・記録と再現性。成果に数えにくいけれど無いと組織が回らない力を、持ち味として見ます。 約10〜15分36問・6領域優劣を出さない 持ち味を見る →

言語化・考えの整理3ツール

「言いたいことがうまく言えない」「モヤモヤの正体が分からない」ときに使います。

CK5 🗣 言語化スキル自己診断 観察力・メタ認知・具体化・構造化・語彙・伝達・習慣の7領域。低い領域から優先度をつけて、トレーニングと目安期間を出します。 約10〜15分42問・4段階レーダー表示 診断をはじめる → CK6 🎯 問題設定力（イシュー思考）診断 現状把握・問題と課題の区別・論点の絞り込み・因果と相関・仮説の立て方・検証の設計。「一生懸命やったのに空振り」を減らすための点検です。 約10〜15分36問・6領域異常対応・原因究明に直結 診断をはじめる → CK3 🧭 強み・キャリア棚卸し（壁打ち型） 採点はありません。12の記述式の問いに答えると、上司との面談やAIとの壁打ちにそのまま貼れる「棚卸しテキスト」を組み立てます。 約15分12問・記述式テキストをコピー ワークシートを開く →

人と動かす2ツール

相手から話を引き出す力と、権限がなくても人に動いてもらう力です。

CK9 👂 聞く力（傾聴・質問力）診断 聞く姿勢・事実を引き出す質問・深掘り・相手の前提を引き出す・要約と確認・聞いたあとの扱い。クレーム一次対応や1on1に直結します。 約10〜15分36問・6領域聞いた質が結果になる場面へ 診断をはじめる → CK10 🤝 巻き込み力（人を動かす力）診断 相手の利害・伝える順番・納得の作り方・対立の扱い・関係づくり・決めたあとの浸透。正しい提案ほど止まる、を減らすための点検です。 約10〜15分36問・6領域部門間調整・浸透 診断をはじめる →

仕事の進め方2ツール

数字の扱いと、仕事の組み立て方です。

CK7 📊 数字で語る力（定量思考）診断 定義の厳密さ・ばらつき・比較のしかた・相関と因果・見せ方・打ち手。統計の知識量ではなく、日々の数字の扱い方を見ます。 約10〜15分36問・6領域KPI・工程能力に直結 診断をはじめる → CK8 🗂 段取り力・仕組み化診断 全体像・逆算と期限・依存関係・余裕の設計・仕組み化・記録と引き継ぎ。速く片づけることではなく、崩れにくく組むことを見ます。 約10〜15分36問・6領域属人化の解消 診断をはじめる →

判断・マネジメントの傾向2ツール

自分の判断や人との関わり方に出やすい癖を、先に知っておくためのものです。

CK1 🧠 思考の癖・意思決定バイアス診断 異常対応や特採判断など、素早い判断が要る場面で誰にでも出る「思考の癖」を6領域で見ます。 約8分24問・4段階関連 B1・B3・B5 診断をはじめる → CK2 👥 マネジメント／リーダーシップ傾向診断 任せ方・フィードバック・育成・対立の扱いなど7領域の傾向を見ます。1on1やOJT計画、部門間調整の実務ページへつながります。 約9分28問・4段階管理者・リーダー向け 診断をはじめる →

実務の力量1ツール

品質実務の型がどれだけ身についているかを、自分で棚卸しします。

CK4 📐 品質実務の力量セルフチェック 定例・マネジメント／異常対応／変化・プロジェクト／予防・維持／教育・OJTの5領域40問。力量マップの自己評価の下書きにも使えます。 約12分40問・4段階関連 E3 力量マップ 診断をはじめる →

使い方の目安

  1. まず自分の持ち味を知りたいなら CK12。8タイプのうちどこで活きるか、誰と組むと強いかが出ます。点数の高さを競うものではありません。
  2. 気が回るとよく言われる／成果に数えにくい仕事をしているなら CK11。見えにくい貢献を、持ち味として言葉にできます。
  3. 環境によって調子の波があるなら CK13。どんな条件のときに力が出るかが分かり、そのまま人に伝える言い方も出ます。
  4. モヤモヤの正体が分からないなら CK5、調べても原因にたどり着けない・改善が空振りするなら CK6。
  5. 面談や1on1の前は CK3。書き出した内容がそのまま持っていける文章になります。
  6. 提案が通らない・現場が動かないなら CK10、話が噛み合わないなら CK9。
  7. 数字の説明で詰まるなら CK7、いつも締切ぎりぎりになるなら CK8。
  8. 判断の癖を知りたいなら CK1、人を持つ立場になったなら CK2 と CK4。年に1回やり直して変化を見るのが向いています。
どのツールも、入力内容はこの端末内（ブラウザ）にだけ保存され、どこにも送信されません。氏名・所属・メールアドレスなど個人を特定する入力欄はありません。共用のパソコンを使ったときは、各ツールの「回答をクリア」を押してから閉じてください。
結果は評価や判定ではなく、自分の考えを整理するための材料です。人事評価や他人の評価には使いません。
